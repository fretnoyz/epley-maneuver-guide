# Epley Maneuver Guide

A mobile-friendly, step-by-step Epley guide for familiar or clinician-diagnosed BPPV. It includes left- and right-ear instructions and timed holds.

## Use

Open `site/index.html` in a modern browser. The app has no build step or external runtime dependencies.

## GitHub Pages

The GitHub Actions workflow deploys the `site/` directory on pushes to `main`. Set the repository's **Settings → Pages → Build and deployment → Source** to **GitHub Actions** if it is not already configured.

## Health information

This is an educational aid, not a diagnostic tool or substitute for medical advice. The correct maneuver depends on the diagnosis and affected side. The guide links to Mayo Clinic and University Hospital Southampton patient instructions.
